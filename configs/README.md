# 配置组织

本目录保存可共享、无凭据的配置；本机覆盖配置使用下述被忽略的位置。未来按功能需要建立 data、model、eval 子目录，不在没有实际配置时预建空层级。

| 分类 | 内容 |
|---|---|
| data | 数据源标识、格式、划分、预处理参数 |
| model | 模型结构、算法与训练超参数 |
| eval | 被测模型版本、加载与设备设置、测评环境、范围、预算和指标协议 |

本机路径、设备和其他本地覆盖配置按需放在 configs/local/；该目录整体被 Git 忽略，不作为共享默认配置。可共享配置保留在本目录的其他位置。
凭据使用环境变量或被忽略的 .env.local，不把真实密钥写入共享配置；不要把个人部署路径作为通用默认。
.env.example 仅说明变量约定，不自动加载 .env 文件；configs/local 也不自带加载器。
路径解析规则、配置覆盖优先级和参数校验须在实际入口实现时明确说明，本模板不宣称已有配置加载器。
每次运行保存最终生效配置与必要哈希，不只保存未解析模板。禁止将权重、原始数据、预测和密钥作为配置文件提交。
