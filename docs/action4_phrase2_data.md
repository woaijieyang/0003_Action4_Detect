# 第二阶段 phrase2 数据契约与执行入口

本文件解释原阶段计划中第二阶段数据任务的实现，不建立第二份阶段计划。数量、随机参数、配额和停止边界以用户本次5000张指令及 `configs/data/action4_phrase2_v001.json` 为准。实际状态查 `outputs/phrase2_generation_v001/STATUS.json`；目录存在和预览通过不代表整批正式可用。

## 目录与准入

正式数据根固定为 `data/phrase2`，保留 phrase2 拼写。train/eval/test 分别4000/500/500图，全部双机；每图两个佩戴侧实例、每实例固定ID0–7八角点。原数据物理根 `data/phrase1` 与兼容入口不改。

每个split使用 `images/`、`masks/`、`geometry/`、`annotations.jsonl`。`.staging/` 是互斥slot领取后的未发布候选；清单只读取accepted事务。检查图、原尺寸裁剪、B0/A0输入预览、失败证据与日志在 `outputs/phrase2_generation_v001`，不写入正式RGB。数据与模型不进入普通Git。

128预览从同一5000配额清单选取。ROOT_PREVIEW_ACCEPTED必须绑定这128张实际RGB身份、配置SHA及根审阅证据；通过后硬链接发布既有样本并打开其余槽位，不再次渲染合格预览。5000合格后仍须完整工程审计、实际batch检查与最终视觉核对，才发布 `data/phrase2/DATASET_COMPLETE.json` 的 `FORMAL_DATASET_USABLE`。当前尚未完成整批发布，不允许启动本阶段正式训练。

## 冻结部件与流水线

使用 `data/action4_scene_templates/phrase2_v003` 三个固定场景，复用已验证DJI、纹理、腕带、安装件和相机转换。DJI实体尺寸、CAD、canonical8顺序与安装矩阵不变；手臂恢复来源原比例，禁止逐图缩放或重新建模。桌面/格子布/衣物保持关联，使用独立版本布局；无random_cloth对象，reset不会重新启用浮片。

执行链是：固定slot → 确定性参数提案 → 每侧有上限的合法朝向预筛 → 双机投影/碰撞/出画/来源检查 → 实际场景依赖图 → 不可变FRAME_SNAPSHOT → 一次Blender RGB与掩码 → 从实际掩码与同帧CAD派生监督 → host校验 → slot事务提交。

worker固定场景常驻，网格、材质、安装与BVH只初始化一次。每次从基准矩阵计算 `C_new=B_new@A_mount` 和根对象整体变换，不累计上一帧变换，不重复变换父子节点。每侧最多64个廉价完整参数提案，找到可行解立即退出，每次claim最多8个完整提案；失败的slot保留类别、seed身份并递增attempt，释放给队列，不无限占用一个worker。最终RGB渲染后不为挽救该张反复调参渲染。

几何连续性检查同时覆盖连接截面、远端出画及上臂重新进入画面。大面片跨入画面但所有顶点都在画外时，使用保守视锥半空间判断；不是只检查顶点是否落在图片内。该筛选不改变手臂或机身比例。

中高遮挡要求最大单个实际遮挡物为自身手腕/前臂，所有安装件合并的统计另报，预筛与终筛使用同一口径；低遮挡允许固定安装件的合理遮挡。局部射线只作预筛和来源统计，正式面积遮挡率必须从visible/amodal PNG重算，不把射线比例当实际面积。

## 坐标、ID与标注

二维坐标左上原点、x向右/y向下，u=x/W、v=y/H。长度以米存变换；历史 `corners_3d_mm` 为毫米，读取时显式除1000。相机K与原生3248×2464图像绑定，捕获坐标为OpenCV方向；Blender转换沿用原实现。

| 字段 | 含义 |
|---|---|
| sample_id / slot_id / split / scene_id | 固定清单身份，失败不改变配额归属 |
| seed / render_seed / attempt | 主种子+split+slot+attempt的独立参数流与渲染种子；并行次序不改变结果身份 |
| instance_id / wearing_side | 1=佩戴左侧、2=佩戴右侧，不根据横坐标排序 |
| corners_px / corner_ids | 固定canonical8的完整投影，ID0–7不随视角重排；隐藏点也保留坐标 |
| bbox_full_xyxy | 八角点包围的完整机身框；不是屏幕框、可见框或含整个支架的框 |
| requested_center_uv / bbox_center_uv | 请求的完整框中心及实际投影框中心；实际分类与配额按后者验收 |
| mask_visible / mask_amodal_expanded | 无损目标实例掩码；amodal为同机身姿态去除外部遮挡后的3倍画布，原图窗口居中 |
| occlusion_inframe / truncation | `1-visible_pixels/amodal_inframe_pixels`；出画面积另记，默认本批为零 |
| actor_pose_capture_by_side / fixed_installation_by_side | 同帧腕部、机身与固定安装矩阵，可复算C=B@A |
| canonical8_geometry | 同帧实际机身/相机变换、固定点顺序与独立投影证据 |
| surface_supervision | 实际visible mask采样点与冻结CAD射线精确交点的NPZ；XYZ米制，含像素、面片ID、K/T与缺失位置 |
| occlusion_sources | 实际场景稀疏射线的遮挡来源统计，明确不同于像素面积真值 |

最终新数据的训练可见性进一步分开记录：`corner_self_visible` 表示固定长方体角点至少一个邻接面朝向观察相机；`corner_ray_clear` 保留实际场景到该虚拟角点的射线结果；`corner_visible` 为二者与在画内条件的交集。旧ray标记及其说明保留，坐标和ID不变。此派生仅作用于第二阶段正式发布，不改旧数据。不能把圆角实体外部空隙中的通射线误作背侧长方体角点可见，也不能人为限定可见点恰好为某个数量：斜看三个面时，固定长方体可有7个可见顶点。可见性与外部面积遮挡率分别监督，不相互替代。

最终派生实现 `data.action4_phrase2_visibility`，检查正视4点、斜视7点、外部遮挡、全遮挡及点ID/坐标不变；它不通过模型重新识别角点，不改变RGB或旧几何标签。

## 随机与配额

完整5000-slot清单在 `outputs/phrase2_generation_v001/SLOTS.json`。位置联合配额、左右各92%/5%/3%遮挡档位及场景500/3500/1000按slot固定；最终统计实际接受标签。每次失败重新抽主要连续参数，外围只从核心区补集抽样。提案均匀不等于约束拒绝后的接受分布均匀；最终必须同时报告实际位置、大小、左右大小、间距×高低差、大小×遮挡、朝向×遮挡。
