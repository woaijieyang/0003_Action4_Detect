# 数据资产

本目录保存原始数据、已授权共享数据的只读入口及项目自有派生数据。数据处理代码位于 [src/data](../src/data/README.md)，不要将两者混用。

可按实际数据需求建立 raw、processed、manifests 等子目录，也可保留项目已经采用的数据分组；不因本说明移动或重命名已有数据。
原始输入只读，派生结果写入新位置。共享数据入口须核对真实路径与访问权限，不通过可写软链绕过边界；本目录存在不授权下载或修改外部数据。

除本 README 外，本目录所有文件与子目录默认被 Git 忽略，包括真实数据清单。必要的小型冻结证据需经过权限、大小和脱敏核查，并按明确文件范围调整跟踪规则，不用强制添加绕过忽略。
测评成绩登记在 [results](../results/results.md)，原始运行输出保留在 [outputs](../outputs/README.md)。数据来源、版本、划分及校验方式见 [实验规范](../docs/EXPERIMENTS.md)。
